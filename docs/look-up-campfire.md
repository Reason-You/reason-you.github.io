# Look Up 篝火

本地原型。进入 `/stars-above/` 即有熄灭的篝火，可随时点燃；页面同时显示本地观测
时间。提交、推送和部署等待确认。

## 篝火与状态

篝火为三火舌火团（高宽比 ≈1.2:1）叠在三根交叉柴上，柴端截面可见，火焰采用
暖橙、琥珀和淡金。未点燃时柴堆轮廓清晰可读；桌面悬停或键盘聚焦命中区时，
柴堆以约 250 ms 浮现极淡暖光作为邀请。桌面按钮为 136 × 108 CSS px，手机为
110 × 88，位于星空底部中央，距 Footer 分别 14 和 12 px。

`fireOn` 是篝火组件自己的 React 状态，初始为 false。原生 `<button>` 的一次
click/tap/Enter/Space 切换一次，名称为 Light campfire / Extinguish campfire。
刷新或重新挂载恢复熄灭，不写 localStorage，不订阅或修改天文状态。

## 烤棉花糖循环

点燃后约 0.5 s，木签带白色棉花糖从右侧探入（700 ms），在火焰旁缓慢旋转
约 1.2 s，奶油色与浅焦糖逐渐加深；烤熟后停在火焰旁轻微摇曳，等待点击。棉花糖
阶段机为 `idle → entering → roasting → ready → eating → entering …`，
每个阶段只持有自己的下一个定时器，切换或卸载即清理，不存在跨阶段泄漏；
熄火从任意阶段经 `retreat → idle` 淡出复位。

烤熟后点击（或键盘 Enter/Space）棉花糖：约 240 ms 缩小淡出，计数 +1，
木签收回，600 ms 后自动送入下一颗白色棉花糖，无限循环。只有烤熟并成功
点击才计数，烤制中或动画中的点击一律无效；快速连击不重复计数。计数只属于
本轮篝火：熄火、刷新或离开页面即归零，不写 localStorage。文字为
`Marshmallow · 1` / `Marshmallows · 2 …`，位于篝火左侧、柴堆高度，11 px
（手机 10 px）低饱和暖棕色，无跳动反馈，为 0 时隐藏。

两个命中区独立：火焰/木柴按钮（z-index 30）只管点火与熄火；烤熟后出现
独立的 Eat roasted marshmallow 按钮（z-index 40，桌面 46 px、手机 44 px
透明圆区，位于棉花糖上方、整体右移避开火焰中心），快速连咬时它在
eating 阶段保持挂载并禁用，吞掉误触，不会穿透熄火。reduced motion 下
棉花糖直接出现为白色静态，短暂等待后直接进入烤熟静态，点击快速淡出，
计数与循环照常，无旋转与长距离移动。

篝火按钮阻断向星空父层传播的 Pointer Events 和 click。恒星按钮、命中检测、
固定名称与 hover 继续使用现有逻辑；已固定的恒星标签在点燃和熄灭时保持不变。

## 图层

由后向前：

1. `z-index: 0`：篝火 SVG、暖光和少量余烬，全部为无指针的装饰层。
2. `z-index: 10`：原有恒星 Canvas、恒星交互与中英文 DOM 标签。
3. `z-index: 30`：透明的篝火命中按钮，仅 focus-visible 绘制辅助色轮廓。
4. `z-index: 40`：烤熟后出现的透明 Eat roasted marshmallow 命中按钮，
   同样仅 focus-visible 绘制轮廓。

装饰层完全位于恒星 Canvas 后方。暖光不绘制到 Canvas；星空容器和 Canvas
始终保持 opacity 1、filter none，无混合模式。火焰与暖光自身的透明度独立变化。

## 动效与性能

- 点燃时火焰以柴面为原点从 55% 高度生长到全高（700 ms 长尾减速），暖光同步从
  85% 扩展到全范围（760 ms）；熄灭反向收缩，约 380–440 ms 完成，比点燃快。
  柴面描边随火光同步淡入淡出。
- 暖光是软边椭圆径向渐变，桌面限制在天空底部 14%、手机 12%，横向扩散
  上限分别为 440 与 300 px，不覆盖 Footer。
- 暖光以 5.8 秒周期在基础强度 92%–100% 间变化；火焰仅作约 2° 偏移和
  ±3% 高度变化，周期约 4.7–5.3 秒。
- 点燃时每 2.8 秒产生一枚余烬，数组上限 3 枚；每枚在 3.8 秒内上升 38–53 px
  并消失。熄灭立即清理生成器，现有余烬完成一次性动画后移除。
- 火焰和暖光循环仅在点燃时启用。篝火不使用 requestAnimationFrame，不驱动
  星图绘制。页面退出会清理余烬计时器，移除装饰元素和 CSS 动画。
- reduced motion 保留按钮和柔和切换，显示静态火焰/暖光；关闭摆动、呼吸和余烬。

## 观测时间与入场

Look Up 在 Canvas 完成绘制后将 `SkySnapshot.date.getTime()` 发布到 Sky Store。
Footer 订阅该时间，以浏览器默认系统时区格式化，显示：

`January 15, 2026 · 21:00 · Facing South`

`skyUtc` 和 `sky` 的日期解析继续复用原实现。固定测试时刻显示该时刻的本地时间；
正常访问随七分钟星图计算周期更新。格式使用 h23，午夜显示 00:00。
Home、Research 和 CV 继续显示原有 Last updated；Footer 右侧保持原样。

- 从其他页面进入 Look Up 时，星图从原背景视场中心下落对齐观星窗口，星空内
  的流星层随之下落淡入；旧背景（含流星）以相同距离、时长和曲线同步下移，
  前 45% 保持满透明度、后段再溶掉——整片星空作为一个世界移动：

- 可见停留约 120 ms 后开始移动（子页面 0.4 s 隐形等待的等价物，避免星空定格）。
- 600 ms 长尾减速 `cubic-bezier(0.16, 1, 0.3, 1)`，前段快速走完距离，尾段
  亚像素级缓停。
- 新星空在前 ~250 ms 淡入同时下落，消除两套星图的硬切换。
- 平时流星持续在整扇天空飞行（回收线约 90% 视口高），位于恒星 Canvas 后方，
  不碰星图像素。
- 离开 Look Up 时做反向交接：星图快照为视口大小的双层结构，底层用背景
  自己的相机与渲染参数（含垂直渐隐）重渲同一份天文快照，顶层是 Look Up
  星图原样位图；双层以 480 ms 加速上收，真实背景（含流星）从下方同步上移
  淡入，前 30% 即升到 ~0.8 透明度、流星全程可见。实测锁步偏差 0.001 px：
  每一瞬间快照底层与真实背景逐像素一致，落地交接不可见；顶层 Look Up 星点
  原位渐溶，无双星、无接缝、无亮度突兀。

透明度只存在于路由切换的过渡瞬间；静止状态下星图、恒星 Canvas 和页面背景
恒为 opacity 1，无 filter 和混合模式。位移只落在星图与背景包装层上，Navigation、
Footer 和篝火不动。直接打开/刷新不触入场动画；reduced motion 直接切换，
不做交叉淡化与位移。完成后清理动画类和 will-change，快照随动画结束移除。

## 对照与验证

固定使用复旦坐标 31.2989° N、121.5035° E，以及 UTC 2026-01-15 13:00。
对照状态 B 为熄灭，C 为点燃；D 为点燃且固定参宿四名称。

| 视口 | 类型 | 天空尺寸 | 绘制 / 可交互恒星 | 篝火触控区 |
|---|---|---|---:|---|
| 1280 × 720 | 桌面模拟 | 1280 × 575 | 87 / 23 | 136 × 108 |
| 1440 × 900 | 桌面模拟 | 1440 × 755 | 93 / 24 | 136 × 108 |
| 390 × 844 | 手机模拟，DPR 2 | 390 × 667 | 69 / 18 | 110 × 88 |
| 375 × 812 | 手机模拟，DPR 2 | 375 × 635 | 69 / 18 | 110 × 88 |

四种视口的 VIIRS 极限星等均为 4.146324479884627。每种视口均对比点燃前后的：

- `window.__sky` 对象引用及完整快照、相机、投影星点与 alpha：一致。
- 恒星 Canvas 的所有 RGBA 通道：**0 差异**。
- 反复切换后的恒星 Canvas 重绘：**0 次**。
- localStorage 内容：一致。

半径、颜色、星等、VIIRS 与天文计算的函数均沿用原实现。星图像素逐通道比较
确认火焰装饰不会修改其输出。

浏览器验证共 **17 组通过**，覆盖：默认/刷新熄灭、重复 click/tap、原生键盘、
亮星 hover/固定与篝火共存、布局无跳动和溢出、底部光范围、余烬自然结束、退出
清理、静态 reduced motion（含双向直接切换、无快照、流星停飞）、125% 浏览器
缩放、UTC/本地参数与时区、七分钟实时更新、入场运动曲线采样与流星随动、移出
星空上收与背景锁步、篝火生长/快熄灭计时、多标签累积/单删/空白保留/页脚清空/
Escape 及静止流星不碰星图像素；另有棉花糖五组：烤制上色采样、烤熟停留与无限
循环计数（含连击不重计、键盘、熄火清零重烤）、四个阶段熄火复位矩阵、手机双
命中区分离与路由清理、reduced motion 静态可玩。125% 缩放下还验证了键盘切换
和星图像素保持不变。

入场实测：可见停留 129 ms，起步后前段速度 0.91 px/ms、尾段 0.06 px/ms
（减速比 ≈15:1），279 ms 星空完全显现，600 ms 动画完整跑完再清理；旧背景
与星图锁步下移，偏差小于 8 px。移出实测：快照与背景锁步上收，
**偏差 0.001 px**；顶层星图渐溶至 0.11，背景从 0 淡入到 1 并落位。篝火实测：
点燃生长 728 ms，熄灭 434 ms。

时区验证：同一 UTC 时刻在 Asia/Shanghai 显示 21:00，在 America/New_York
显示 08:00；`sky=2026-01-15T08:00` 在纽约得到相同星图时刻。实时时钟推进到
下一次计算后，Footer 与新快照同时显示 21:07。

`npm run build`、`npm run lint`、`npx tsc --noEmit` 和 **11/11** 星空/时间单元测试
通过。机械视觉检测无新增问题。
