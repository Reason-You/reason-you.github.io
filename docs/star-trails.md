# Time Travel（时间旅行）

Look Up 页面左下角的时间旅行控件：双三角快进图标与`Hold`文字按钮、`time 1x` 胶囊，以及在
天空停留在未来时刻时出现的 `now` 返回按钮。

## 交互

- **按住播放按钮**：时间加速流逝，天空旋转，恒星拖出累积的星轨。按住
  越久倍率越高——从 60x 起，每 800 ms 翻倍，封顶 7200x（1 秒现实 = 2 小时
  天球）。快进时星点半径收至轨迹线宽的一半，亮星光晕淡去；胶囊实时显示`time 240x`。
- **松开**：回到 1x，天空从快进到达的时刻继续正常流动。偏移持续存在，
  胶囊显示 `time +2h 14m · 1x`（明示"拨快了 2h14m、正按 1x 走"）；
  轻点 `now` 返回当下。偏移跨朝向、地点切换和昼夜预览保留，离开
  Look Up 页面自然复位。星轨完整保留20秒，再用4秒平滑淡出，星点位置、大小与光晕同步恢复。
- 键盘：按住Enter/Space按相同速度曲线快进，松开停止。
- 常速1x时每秒推进星空、网格、星名位置与页脚时钟，完整天文解算每7分钟更新一次。
- reduced motion：不跑连续动画，单次静态合成 1 小时星轨图，保留20秒后
  用4秒淡出并恢复星点位置、大小与光晕；天色按历史时刻记录，星空只绘制最终帧。
  时间偏移与`now`语义不变。
- 从按住开始到星轨完整消失，实时流星层持续隐藏，动画循环暂停。
  20秒保留与4秒淡出结束后恢复，并重置帧间隔。普通观星时，流星在物理天空中
  保留飞行方向，随转身、抬头和低头一起投影。
- 页脚显示设备时区的日期、24小时时钟与UTC偏移，UTC偏移随显示日期的夏令时规则变化。
  手机保留短日期，例如`01/16 03:40 UTC+8`。
- `Grid`默认关闭，主动打开后显示赤经、赤纬网并突出天赤道。
  经线每2h一条、纬线每15°一条，仅保留线条；网格与恒星使用同一时刻和相机，
  点击可穿透到星星。
- 随机选址按当前模拟时刻筛选天文夜晚，地点切换保留当前时间基准与偏移。
- 拖动天空可连续转身、抬头或低头，松手后视角停住，天空继续以1x推进。
  轻点仍然选星；移动超过10px后开始拖动，已记录的星轨随天空重投影，时间偏移保留。
  拖动时只更新星空和网格，松手后恢复星名与点选。四方向按钮保留快捷切换，
  自定义视角下显示复位按钮，返回上次预设朝向与默认仰角。
- 拖动、四向切换、视角复位与窗口缩放均保留原松手时刻的20秒保留与4秒淡出计时。
  曝光覆盖经过光污染过滤的完整天球，转向任何方向均显示同一段历史时间的轨迹；
  重画只改变视角，切片亮度保持。
- 默认朝北，北侧篝火固定在地面上；0°地平线与篝火共用本地相机，天空按
  模拟时间旋转。地面遮住下方星轨，名称与点选保持在天空范围内。

## 天文语义

- **恒星**：天球绕观测者天极做刚体旋转，相机绕极轴转 +θ 等价于天空
  前进 θ，每帧 O(1)，不重算恒星。地平线裁剪随旋转的天顶同步：东方
  恒星升起、西方恒星落下，对任意快进时长（含跨昼夜）成立。
- **太阳**：每帧用 astronomy-engine 按当前虚拟时刻与观测地经纬度精确
  解算太阳高度（~0.02 ms/帧），晨昏与星等可见度随之实时变化——快进
  穿过日出时星光平滑降到白天下限（40%），跨过日落进入下一夜时恢复
  满亮，与当地当天的真实日出日落分秒同步。
- **星轨**：全天持续记录。深夜生成的轨迹保持满亮，按住越久，累积的
  弧线越长，历史窗口为15个模拟小时；白天保留约18分钟的短尾，新轨迹持续可见。暮光期间，年龄
  衰减与夜间保留度平滑衔接，每片透明度只随记录历史降低；已经冲淡的
  旧轨迹保留衰减后的亮度，完全淡出的切片回收，下一夜由新轨迹继续
  累积。亮度不同的相邻切片在交界处使用同一个亮度，沿原弧线连续渐变；
  每片中心保留原有亮度，曝光范围和衰减规则保持。渐变以完整弧端投影定位，
  转向和画框裁切延续同一条渐变。同位置、同样式的双星轨迹保持单次覆盖。
  同亮度切片继续复用聚合路径，以平直端帽和共享端点衔接。松手前补画到最终虚拟
  时刻，保留轨迹末端作为星点锚点；重算天空后，星点从锚点平滑回到
  正常投影坐标，位置、大小与光晕随星轨淡出同步恢复。
- **时间切片**：按固定的10分钟模拟时间边界记录曝光时段与透明度，
  恒星的历史位置由曝光基准星表及地轴旋转重建。历史窗口按模拟年龄淘汰，
  与设备帧率无关；绘制时按各历史时刻的本地方向裁剪地平线，再裁当前视场。
- **单次计偏**：基准相机接收已包含时间偏移的快照——松开瞬间按
  `实时时钟或固定预览时间 + 偏移`全量重算并用基准相机渲染接管；快进期间的旋转一律
  相对快照自身的纪元，从根上排除偏移被计入两次的可能。
- **共享时钟**：`skyStore.timeOffsetMs`保存模拟时刻相对基准时钟的偏移，绘制和选址均加一次。
  实时快进结束时扣除本次现实经过时间，使松手前后保持同一模拟时刻。

## 实现

| 文件 | 职责 |
|---|---|
| `src/lib/sky/star-trails.ts` | 极轴、Rodrigues 相机/天顶旋转、`snapshotAtOffset`、速度爬坡闭式积分、偏移格式化；`TrailBuffer`保存完整星表、曝光时段及不可逆衰减，按世界空间分格筛选当前视场候选星，缓存聚合路径与局部渐变路径 |
| `src/lib/sky/trail-geometry.ts` | 天球轨道方向、整球空间索引、曲线细分与当前视场投影；历史轨迹跨地平线和视锥裁剪，同星连续段共用折线路径 |
| `src/lib/sky/astro.ts` | `solarSkyState`（单太阳高度解算）；`computeSky` 额外返回全天球 `celestialStars` |
| `src/lib/sky/renderer.ts` | 星点与星轨共享星等线宽；`trailPositionBlend`控制锚点位置，`trailBlend`控制星点半径与光晕强度，保持返回的真实投影、星点数量和透明度 |
| `src/components/sky/TrailControls.tsx` | 播放按钮、胶囊、`now` 按钮；pointer capture 长按，键盘 Enter/Space |
| `src/components/sky/LookUpSky.tsx` | 基准相机与共享时钟；普通及静态曝光记录天色；松开全量重算；视角变化重投影星轨及世界方向端点，保留原20秒与4秒计时 |
| `src/lib/sky/guides.ts`、`src/components/sky/SkyGuides.tsx` | 赤经赤纬网、天赤道与天极，按当前相机与天顶裁剪到地平线及画框 |
| `scripts/test_star_trails.cjs` | 旋转正交与手性、恒星日复位、四朝向画面内对齐（≤2.5 px）、东升西落集合对齐、真实昼夜周期、暮光连续性、深夜累积、白天短轨、旧轨迹衰减与回收、普通与静态记录一致性、环形缓冲 |

守卫：快进期间暂停 7 分钟解算定时器、清空星名与交互焦点；朝向/地点/
dateOverride 变化、窗口缩放、页面隐藏、组件卸载都会先结算快进。
`prefers-reduced-motion` 走静态合成路径。
