# Look Up

独立路由 `/stars-above/`。导航顺序为 Home · Research · CV · Stars Above。
观星页沿用现有 Navigation、Footer、主题和主页星空/流星行为。

篝火、观测时间与入场过渡见 [look-up-campfire.md](look-up-campfire.md)。

## 页面与相机

- Look Up 在固定导航下方与 Footer 上方使用全部剩余空间；仅此路由采用
  `100dvh` flex 布局，其他页面保留原有 `main` 高度。
- 默认朝北 0°，可按星空右下角的方向按钮依次切换北 0° → 东 90° → 南 180° →
  西 270°。四向预设中心高度角上限为35°，按画框调整，使地面保持底部窄带，
  同时完整显示北侧篝火。鼠标或单指拖动超过10 CSS px后
  连续转动视角，高度角限制在 0–90°，松手立即停住；轻点继续选择恒星。
  自定义视角时方向旁出现复位按钮，返回最近的四向预设及适配窗口的高度角。
  桌面水平视场为 100°；宽度小于 640 CSS px 时垂直视场为 75°，水平视场
  根据容器宽高比计算。
- `?facing=north|east|south|west` 指定入场方向；普通进入默认朝北。视角
  不写 URL 或本地存储。四向切换清空恒星名称，300 ms 交叉淡化；reduced
  motion 直接切换。连续拖动重投影同一天文快照，拖动时隐藏名称，松手后
  恢复仍在视场内的名称。开始拖动会停止快进，保留已前进的时间；完整天球的星轨
  随视角重投影，从原松手时刻完整保留20秒，再用4秒淡出。四向切换、复位和
  窗口缩放继续沿用同一计时；星轨显示期间四向切换直接接入新视角。
  篝火、烤制阶段和计数保留。
- 0°地平线使用本地相机投影，下面为不透明平坦地面。恒星、星轨、普通流星、
  星座线与网格受地面遮挡，名称及点选范围限制在天空内。快进时地面与北侧
  篝火保持原位；篝火随转身和抬头离开视野，烤制状态继续保留。
- 共用 Astronomy Engine、HYG v4.1、VIIRS、Sky Store 和 URL 时间/位置覆盖。
  Look Up 绘制一张完整 Canvas（流星层位于其后），主页保留淡星空与流星
  两层 Canvas。Look Up 的流星回收线放宽到约 90% 视口高，覆盖整扇天空。
- 星点大小、B−V 配色和白天可见性沿用现有映射；Look Up 去除主页的垂直渐隐，
  透明度提高 15%，最大 0.96。地点的极限星等在桌面与手机上相同。

## 名称与交互

| 统计对象 | 数量 |
|---|---:|
| HYG 中 mag ≤ 3.0 的条目 | 179 |
| 其中有英文专名的条目 | 145 |
| 核实中文对应关系的条目 | 145 |

条目以 HYG ID 关联，不使用坐标近邻或英文名称猜测。HIP、HD、拜耳标识、
出处和证据保存在 `src/lib/sky/star-names-data.json`；来源说明见
[sky-star-names.md](sky-star-names.md)。Castor 与南门二的 A/B 分量分别保留。

只有通过当前星等过滤并位于可见视场的已核实名星参与交互。鼠标命中半径
16 CSS px，触控/笔输入 28 CSS px；选择最近星点，几乎重合的分量优先亮星。
默认无标签；hover 临时预览，click/tap 固定。名字**累积显示**：连续点击
多颗星会同时保留多个名字，再点已有名字的星单独移除它；页面
提供 Clear names 一键清空（有名字时出现），Escape 在焦点位于星空
内时等效。空白处点击不清除。手机与电脑一致。换地点/时间导致某星离开
视场时，仅收走该星的标签；标签状态在离开并返回 Look Up 后保留。
DOM 标签显示中文与英文两行，180 ms 淡入淡出，限制在天空内。
Tab、Enter/Space 与 Escape 提供键盘探索与关闭功能。

## 本地预览与复现

```sh
npm run build
npm run lint
npx tsc --noEmit
npm run test:sky

# 在一个终端运行静态预览
python3 -m http.server 3001 --bind 127.0.0.1 --directory out

# 在另一个终端运行浏览器验证与截图
mkdir -p .cache/look-up-preview
playwright-cli -s=look-up open http://127.0.0.1:3001/stars-above/
playwright-cli -s=look-up --raw run-code --filename=scripts/capture_look_up.cjs
```

## 开场轻提示

开场轻提示按当前会话最多显示一轮。页面在前台且星空就绪1秒后，播放旁显示
`Hold for trails`；6秒未操作后淡出，木柴仍可见时接着显示`Click to roast`。
第一颗棉花糖烤熟后可显示一次`Click to taste`。手机使用`Tap`，减少动态效果
模式的播放文案为`Click for trails`或`Tap for trails`。每条均可点击文字关闭，
200ms退场期间继续拦截点击；操作原对象也会结束开场引导。已成功使用的功能
记录在本地，后续不再提示。原开场星名提示由这组短提示替代。

时间按钮使用双三角快进图标与常驻`Hold`文字，按住时图标周围显示细淡金色圆环。
尚未成功长按的访客第一次轻点后显示`Press & hold`，6秒后退场，也可点击关闭；
每次访问最多提醒一次。减少动态效果模式使用`Click`或`Tap`文字，点击生成静态星轨。

## 视场与数据范围

手机纵向窗口优先展示猎户座；完整冬季大三角位于桌面宽视场中。
现有 HYG 子集保留至 6.5 等，因此 NamibRand 的 7.7 等 VIIRS 极限仍以现有
星表范围绘制。A/B 中文后缀表示系统分量，传统中文名称本身属于星系统。
